# petcare
Projeto desenvolvido no âmbito da unidade curricular de Programação Web - Cliente.

# Tema
PetCare - serviços de cuidados para animais de estimação.

# Público-alvo
Pessoas que têm animais de estimação e procuram serviços para os seus animais.

# Objetivo
Desenvolver um sítio Web responsivo e acessível para apresentar os serviços da PetCare e disponibilizar informação aos utilizadores

#Tecnologias
- HTML
- CSS
- JavaScript
- Bootstrap
