# Guia de Estilo - Projeto PetCare

## 1. Tipografia
O projeto utiliza uma tipografia limpa, moderna e altamente legível para garantir uma excelente experiência de leitura em qualquer dispositivo.
- **Família tipográfica principal:** `'Segoe UI', Tahoma, Geneva, Verdana, sans-serif`
- **Hierarquia e Tamanhos:**
  - `h1` (Título Principal): `2rem` (32px), cor verde escuro (`#1b4332`), utilizado para identificar o tema principal da página.
  - `h2` (Títulos de Secção): `1.5rem` (24px), cor verde floresta (`#2d6a4f`).
  - `h3` (Subtítulos): `1.2rem` (20px), cor verde floresta (`#2d6a4f`).
  - Corpo de texto (`p`): `1rem` (16px), com `line-height: 1.6` para assegurar o espaçamento ideal entre linhas.

## 2. Paleta de Cores e Rácios de Contraste (WCAG 2.2)
A paleta de cores foi desenvolvida tendo em conta a identidade visual da marca e validada face aos rácios mínimos de contraste exigidos pelas normas **WCAG 2.2** (mínimo de **4.5:1** para texto normal e **3:1** para texto grande).

1. **Verde Floresta (`#2d6a4f`)** - Cor principal de destaque.
   - *Utilização:* Cabeçalhos, títulos `h2`/`h3` e cabeçalhos de tabelas.
   - *Contraste com texto branco (`#ffffff`):* **6.39:1** — **Aprovado** (Cumpre os requisitos para texto normal e grande).

2. **Verde Escuro (`#1b4332`)** - Tom profundo de contraste.
   - *Utilização:* Títulos principais (`h1`) e fundo do rodapé.
   - *Contraste com fundo branco / claro:* **11.07:1** — **Aprovado**.

3. **Verde Menta Claro (`#d8f3dc`)** - Tom claro para hiperligações.
   - *Utilização:* Links de navegação no cabeçalho (`nav a`).
   - *Contraste sobre fundo verde floresta (`#2d6a4f`):* **5.4:1** — **Aprovado**.

4. **Verde Suave (`#D4E8D7`)** - Tom claro para links do rodapé.
   - *Utilização:* Links do rodapé (`footer a`).
   - *Contraste sobre fundo verde escuro (`#1b4332`):* **8.61:1** — **Aprovado**.

5. **Cinzento Claro / Fundo (`#f4f6f4`)** - Cor neutra de fundo.
   - *Utilização:* Fundo geral das páginas (`body`) para evitar fadiga visual.

6. **Cinzento Escuro / Texto (`#2b2b2b`)** - Cor base para os textos.
   - *Utilização:* Corpo de parágrafos (`p`).
   - *Contraste com o fundo claro (`#f4f6f4`):* **13.03:1** — **Aprovado**.

Todos os rácios foram calculados com a ajuda do website: https://webaim.org/resources/contrastchecker/
